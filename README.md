# Ready Calendar

Ready Calendar is a polished, modern React landing page that presents a calendar product as a collaborative workspace for teams. The project transforms a static UI concept into a responsive, visually rich frontend experience with carefully crafted sections, custom illustrations, and refined spacing.

## Overview

This app showcases a complete marketing-style experience for a calendar product, centered around the idea that a calendar can go beyond scheduling and become a place for meetings, planning, collaboration, and productivity. It is built as a frontend UI implementation with React, Vite, and Tailwind CSS.

The experience includes several sections that guide users through the product story:

- A hero section introducing the concept of a smarter calendar
- A "Superpowered" section highlighting key product value
- An upgrade-focused section emphasizing product benefits
- A detailed "Feel Ready" section with immersive card-based visuals
- A calendar-focused section that reinforces the product experience
- A final call-to-action and footer

## Features

- Responsive, polished landing page layout
- Modern section-based composition with strong visual hierarchy
- Custom UI cards, badges, and visual accents
- Inline SVG illustrations and decorative strokes
- Tailwind-based styling for fast and maintainable design work
- Optimized layout behavior for desktop and mobile screens

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository
2. Navigate to the project folder
3. Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

This will start the development server. Open the local URL shown in the terminal to view the app in the browser.

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Available Scripts

- `npm run dev` — starts the Vite development server
- `npm run build` — creates a production build
- `npm run preview` — previews the built app locally
- `npm run lint` — runs ESLint checks
